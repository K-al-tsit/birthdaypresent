# 当前视觉方向

网页整体仍以《だから僕は音楽を辞めた》MV 的晴空与黄昏意象作为环境主题，但首页歌单封面已经改为用户提供的真实黄昏城市照片。

参考：
- 官方 MV 页面：https://yorushika.com/news/detail/11096
- MV 画面报道：https://spice.eplus.jp/articles/233555
- 官方分享的黄昏栈桥画面：https://x.com/nbuna_staff/status/1378264580024004609

背景继续使用原创 SVG 天空、云、海面与栈桥，不复制原视频素材，不使用生成式图片。白天为高饱和蓝天与亮白云，黄昏为靛蓝、紫色、珊瑚粉和暖橙。

## 首页数字歌单

首页右侧改为主流数字音乐平台式的方形歌单展示。封面直接使用仓库根目录的 `cover.jpg`，避免二次压缩造成清晰度损失。封面只保留极简的 `21` 与 `for H.C.`，日期、歌曲数量等信息移到封面下方：

- 21
- For H.C. · 2026
- 21 首歌

桌面端封面作为首屏右侧主视觉；手机端约占 80–86vw，优先保证照片细节和触控阅读节奏。封面上的 `21` 与 `for H.C.` 固定在左下角。

## 自适应播放器配色

页面加载首页封面、以及播放器切换到带嵌入封面的歌曲时，会通过 Canvas 对当前 artwork 做低分辨率取样，提取深色、中间色、暖色和高光色，并写入 CSS 自定义变量。Mini Player、全屏播放器背景、按钮和进度强调色据此轻微变化。取色失败时使用预设的靛蓝 / 暮紫 / 玫瑰色回退值，不影响播放功能。

页面晴空 / 黄昏主题保持独立，不会被歌曲封面替换；动态取色只影响播放器和歌单周边的局部氛围。

显示文案与时段设置集中在 `assets/content.js`；完整编辑索引见《文字编辑指南.md》。当前正式开发版本以 `main` 分支为准。


## CSS 维护边界

`assets/styles.css` 作为历史基础视觉层保持冻结；跨浏览器修复、最终响应式规则和播放器可读性约束统一放在后加载的 `assets/stability.css`。这样后续调整不再继续在同一个大文件末尾叠加覆盖规则，避免选择器优先级和历史补丁互相影响。
