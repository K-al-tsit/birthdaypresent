# 当前视觉方向

只使用《だから僕は音楽を辞めた》MV 的晴空与黄昏意象。

参考：
- 官方 MV 页面：https://yorushika.com/news/detail/11096
- MV 画面报道：https://spice.eplus.jp/articles/233555
- 官方分享的黄昏栈桥画面：https://x.com/nbuna_staff/status/1378264580024004609

简化为原创 SVG 天空、云、海面与栈桥，不复制原视频素材，不使用 imagegen。白天为高饱和蓝天与亮白云，黄昏为靛蓝、紫色、珊瑚粉和暖橙。保留原有桌面布局、文案和卡片歌单；首屏音乐意象改为方形专辑封面，不再使用黑胶唱片。专辑封面直接使用当前晴空 / 黄昏 SVG 作为封面画面，并叠加极简 21 / FOR H.C. 排版。手机端以 vivo X100s 竖屏为首要验收设备，并兼容约 360–460 CSS px 的 Android 视口。顶部设置在小屏收纳为单一图标弹出面板，播放器强化触控尺寸、进度拖动和底部安全区。

显示文案与时段设置集中在 assets/content.js；完整编辑索引见《文字编辑指南.md》。本版按用户确认推送到 birthday-21 分支；未主动执行部署。
